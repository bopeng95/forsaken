# Kefka DM

A browser-based practice simulator for selected mechanics of FFXIV's **Dancing Mad (Ultimate)**.

**[kefka-dm.vercel.app](https://kefka-dm.vercel.app)**

## Supported mechanics

- **Forsaken** (Phase 2) — following the **Kroxy-Rinon (KR)** strat.
- **Kefka Says** (Phase 4) — following the **Gazes Mid** raidplan.
